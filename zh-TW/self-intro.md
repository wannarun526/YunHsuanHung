## 1. 封面

大家好，我是洪昀璿，英文名字是 Sean。我是軟體工程師，有 6 年正式系統的開發經驗，主要做後端，也做過前端、行動 App 和 AI 整合。接下來大約用幾分鐘介紹我的背景和做過的專案。

## 2. 關於我

簡單講幾個數字：我有 6 年的正式系統開發經驗，做過最大的平台是 XSGD 的支付系統，超過 10 萬名使用者、每天超過 10 萬筆交易。我的經歷大多是在金融系統，包括銀行、保險和穩定幣支付，現在也服務 ERP 供應商和家電製造商這類企業客戶。我可以從需求訪談一路負責到上線維運，也在團隊裡帶工程教育訓練。

下面是我的職涯：2023 年到現在在新逸科技。我目前住在台南。

## 3. 專案概覽

這頁是我經歷過的主要六個專案，每個專案技術棧都不太一樣後續會一一介紹。上排三個是近三年的：鼎新的 DigiKnow 平台、櫻花台灣官網和新光人壽的 CMS。下排是之前的金融系統：StraitsX 的 XSGD 支付流程、玉山銀行的零售銀行系統，還有我在昕力的第一份工作。每張卡片下面的簡圖，藍色框是我主要負責的部分。接下來挑幾個詳細說明。

## 4. 鼎新電腦 DigiKnow 就享知平台

第一個專案是鼎新電腦的 DigiKnow 平台，會員超過 10 萬人。這裡挑三個我處理過的正式環境問題。第一個是積分兌換，很多人同時兌換時會搶同一筆庫存，造成競爭條件和死鎖，我用悲觀併發控制解決。第二個是 API 逾時，我找出 N+1 查詢、補上索引、加了快取層，優化到一秒內回應。第三個是後台匯出資料時記憶體不足，我改成分批分頁處理。除此之外，我也做了 AI 助理、Kubernetes 監控，以及 iOS 和 Android 的 App。

## 5. DigiKnow 系統架構

這是 DigiKnow 的整體架構。前台是 Nuxt 3，App 用 React Native，後台是 Vue 3，三個前端都打到 NestJS API。舊的 PHP API 正在逐步退場，由 NestJS 接手。資料放在 MySQL，schema 用 Flyway 做版控，Redis 負責佇列。外部則串接 Google Cloud 的儲存與分析服務、Gemini，以及鼎新內部的登入和簡訊系統。

## 6. 跨團隊合作與系統升級

另外兩個專案。櫻花台灣的官網遇過問題是頁面很慢，我主導跨部門調查，跟基礎架構和資料庫團隊一起，一層一層找出瓶頸，最後把會逾時的端點優化到一秒內。新光人壽的保單平台，我把前端從 Angular 11 升級到 17，跨了六個主要版本，開發效率提升八成以上；同時維護 Java 的 CMS 後台，也跟 QA 團隊合作做了 AI 輔助測試的原型。

## 7. 櫻花台灣 官網系統架構

櫻花官網的架構比較單純：外面是 Nginx 反向代理，後面是 ASP.NET Core MVC，前台和後台在同一個應用程式裡，後台用 Identity 做登入驗證。資料透過 EF Core 存到 MSSQL，也處理舊站網址轉址和 SEO，產品資料則從舊的產品資料庫匯入。剛剛講的效能調查，就是沿著這條路徑，從應用程式、資料庫到基礎架構一層一層查。

## 8. 新光人壽 CMS 系統架構

新光人壽的 CMS 是內容發佈系統。編輯在 Angular 後台編輯內容，透過 WildFly 上的 Java API 存到 SQL Server；發佈時由 Node 的 SSR 服務產生靜態頁面，再傳到 Web 主機，訪客看到的是靜態官網。登入串接新光的 SSO，另外也整合了幾個外部系統。

## 9. 高監管、高流量的金融系統

在這之前，我主要做金融系統。在 StraitsX，我開發 XSGD 的鏈下支付流程，處理鏈下帳本和鏈上轉帳之間的非同步結算，重複或失敗的事件用冪等和重試確保正確，也負責對帳。在普鴻資訊，我負責玉山銀行的零售銀行系統，主導開發符合法規要求的導覽驗證模組，也用 Azure Pipelines 自動化發布，讓部署錯誤率降到零。

## 10. 技術能力

技術方面，後端我用過 C# / .NET、NestJS、Java 和 FastAPI；前端熟 Angular，也做過 React、Vue 和 React Native。資料庫主要是 SQL Server 和 MySQL。我比較擅長的是效能和可靠性，像併發控制、查詢和索引優化、快取，以及正式環境的問題診斷。另外我平常用 Claude Code 開發，也負責需求訪談和團隊的教育訓練。
